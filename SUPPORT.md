# Support

- **Usage questions:** Open a GitHub Discussion when enabled, otherwise an issue. Read `README.md` and `docs/consumers.md` first.
- **Bugs in token values or exports:** Issue with the token name, expected vs actual value, and which consumer broke.
- **Meridian- or Glamor-only bugs:** File them in those repos unless the root cause is here.
- **Security:** Never a public issue. See [SECURITY.md](SECURITY.md).

No paid support or SLA. Maintainers review issues when they can.
